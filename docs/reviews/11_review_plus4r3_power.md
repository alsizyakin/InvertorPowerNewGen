# Ревью силовой части: InvertorPowerNewGen, ветка `rev0.1-plus4` (b78f01b)

*Ревьюер: субагент «инженер силовой электроники», 2026-10-20. Текст — как получен.*

**Вердикт.**
- Четыре коммита после `50ad933` сделаны аккуратно.
  - DRC на копии: 0 ошибок, 0 неразведённых, 0 расхождений; одно предупреждение silk у C11. Перезалитая плата совпала с файлом ветки байт в байт.
  - `hv.py` — те же 24 места. Ни одного отрезка вне 0/45/90°.
  - Затворные цепи после `octo.py` не длиннее, а короче: HO_DRV 3.91 → 3.29 мм, LO_DRV (B, A) 2.91 → 2.36 мм, затвор верхнего HS +0.14 мм. Новых зазоров < 0.5 мм нет.
- **Главное — `cflow.py` занижает сопротивление меди узла в 1.3–2.4 раза**, и при мельчении сетки число падает, а не сходится: узел A 0.394 / 0.323 / 0.196 мОм при h 0.2 / 0.1 / 0.05 мм (P15).
  - Причина: пэд каждой виа — идеальный диск r 0.3 мм. Виа узла — 0.5/0.3 с шагом 0.5 мм, диски перекрываются, поле виа становится цепочкой без сопротивления.
  - Исправленная модель, LS / HS при 100 А: C 0.574 / 0.720, B 0.573 / 0.730, A 0.515 / 0.665 мОм. В CHANGELOG — 0.433 / 0.566, 0.24 / 0.38, 0.323 / 0.458. Фаза B не лучшая: три фазы равны.
- Решения, принятые по cflow, при этом верны — относительные изменения модель даёт правильно:
  - фаза A: LS 0.679 → 0.506 мОм (−25 %); потери в меди в 2 мм от пэда шунта 2.50 → 1.18 Вт, теперь как у B и C (1.12 / 1.07 Вт);
  - VDC −10…−16 %; E6 стоит +1.4…1.8 %, тепловая роль ничтожна;
  - F15/F16 дали узлу C −12 % (0.659 → 0.577 мОм) — этого числа в CHANGELOG нет.
- Тепло: медь узла при 85–106 А RMS — 4.3–7.3 Вт на фазу при 20 °C, до ~9 Вт горячая, плюс шунт 2.2–3.4 Вт. Это в 1.5–2 раза больше, чем следует из чисел cflow.
- INA240 (P16): при 48 В запас до предела 90 В — 3–7 В (стенд 83–87 В). Снизу после Кельвина HS по оценке −5…−10 В при пределе −6 В. INA241A2 (−20…120 В) закрывает 48 и 72 В, при 84 В до предела 15–25 В. **У INA241 вывод 4 (NC) по даташиту надо заземлить**, на плате он свободен — «пин в пин» без этого неполный.
- Перекладка фазы A чистая:
  - In2 узла до шунта одним куском;
  - линии термистора — между In1 GND и In3 GND;
  - плоскость +3.3V цела (1524.7 → 1517.3 мм², один кусок);
  - под головкой правого винта виа узла 32 → 0.
- Виа сшивки VDC на верху колонок стока (y 74.5) сузили In3 GND над окнами стоков HS с 2.45 до 1.35 мм. Это путь возврата петли коммутации. По постоянному току выигрыш реален, по ВЧ цена по оценке ≤ 0.02 нГн. Новых виа там не ставить (P17).
- R снаббера 2 × 0805 — мощность из CHANGELOG подтверждаю, это верхняя граница. Брать ERJ-P06, не ESR10 для 84 В. Трафарет — под выводы 0805, а не под пэд 0612 (P19).

**Как проверял.**
- Копия проекта во временном каталоге, kicad-cli 10.0.3, `run_drc.sh`. Файлы проекта не менял.
- Платы пяти коммитов (`git show`), сравнение своим скриптом:
  - посадочные места не двигались;
  - виа −84 / +43;
  - отрезки и длины по цепям.
- На `50ad933` и `b78f01b`: `hv.py`, `bridges.py`, `islands.py`, `final_checks.py`, проверка углов всех отрезков.
- Свои картинки слоёв (заливки, дорожки, виа, контур) у прохода A, верха колонок стока и пазов.
- cflow:
  - воспроизвёл числа CHANGELOG: C / B / A LS 0.433 / 0.241 / 0.323 мОм;
  - сходимость по сетке h 0.2 / 0.1 / 0.05 мм;
  - вариант «стенка стакана»: стакан связан с медью слоя по кругу r = d/2 + 0.025 мм (0.175 мм), а не по пэду 0.3 мм. Ещё один вариант — с вырезанными отверстиями;
  - пересчёт случаев узла, VDC и GND на `9005041`, `bd1f33e`, `b78f01b`, для узла C ещё на `50ad933` и `b2f3c90`;

- Независимая 1D-оценка: ширины меди по слоям поперёк прохода с шагом 0.025 мм, R = Σ Δy·ρ□ / ΣW при идеальной связи слоёв. Это нижняя оценка участка.
- Снаббер: RK4, ветвь L 1.1 нГн – R 0.5 Ом – C 4.7 нФ, линейный фронт узла 6–30 нс.
- Даташиты TI: INA240 (SBOS662C) и INA241A/B (SBOSA30D) — предельные режимы и назначение выводов.

## Находки

### P15 — средняя. cflow занижает сопротивление меди узла в 1.3–2.4 раза; число зависит от сетки; ранжирование фаз неверно
**Где.** `tools/rev01_layout/cflow.py`, `_raster()` и `solve()`; таблицы CHANGELOG «Анализ растекания тока», «Результат» и E6.

**Факты.**
- `kpcb.load` не читает размер виа. Поэтому `cflow` берёт 0.6 мм для всех виа со сверлом 0.3 мм.
- Все клетки в радиусе 0.3 мм связаны со стаканом проводимостью 1e5 См. Значит, пэд — идеальный проводник на каждом слое.
- У узла 86 / 57 / 131 виа (A / C / B) 0.5/0.3 с шагом 0.5 мм, в шахматку 0.56 мм.
  - Диски r 0.3 перекрываются.
  - Клетка в перекрытии замыкает соседние стаканы, и поле виа становится цепочкой без сопротивления.
- Сходимости нет. Узел A, LS, модель как есть:

| h, мм | 0.2 | 0.1 (CHANGELOG) | 0.05 |
|---|---|---|---|
| Медь, мОм | 0.394 | 0.323 | 0.196 |
| Пик |J| на B.Cu, А/мм² | 1065 | 1312 | 1782 |

- Нижняя 1D-оценка для одного участка y 88.5–100: медь без отверстий, все слои идеально связаны. Стенки стаканов примерно возмещают вырезанную медь.
  - B — 0.336, C — 0.326, A — 0.284 мОм.
  - cflow для **всего** пути B даёт 0.241 мОм, меньше этого одного участка.
  - Проход A (y 92–98.5): по cflow ≈ 0.085 мОм, оценка снизу 0.20 мОм.
- Вариант «стенка стакана» (r 0.175 мм, перекрытий нет) сходится: h 0.1 → 0.05 меняет R на 3–5 %. С 1D-оценкой прохода он совпадает: A 0.19 против 0.20 мОм.

| 100 А, медь, мОм, LS / HS | C | B | A |
|---|---|---|---|
| CHANGELOG (cflow, h 0.1) | 0.433 / 0.566 | 0.24 / 0.38 | 0.323 / 0.458 |
| «Стенка стакана», h 0.05 | 0.574 / 0.720 | 0.573 / 0.730 | 0.515 / 0.665 |
| Отверстия вырезаны, связь по кольцу r 0.2 | 0.534 / — | 0.46–0.48 / — | 0.43–0.46 / — |

- Что не меняется — тот же вариант, h 0.05:
  - фаза A по `lay_P4d`: LS 0.679 → 0.506 (−25 %), HS 0.828 → 0.656 (−21 %). В CHANGELOG −24 / −18 %;
  - потери в меди в 2 мм от пэда шунта, 100 А: A 2.50 → 1.18 Вт, B 1.12, C 1.14 → 1.07 Вт;
  - перцентиль 99 |J| в кольце 0.2–0.5 мм: A 2477 → 1037, B 952, C 958 → 882 А/мм². После переделки три фазы у шунта равны;
  - E6: A 0.506 → 0.515 (+1.8 %), C 0.566 → 0.574 (+1.4 %). В CHANGELOG +0.9 / +0.2 %;
  - F15/F16 (`b2f3c90`), узел C: 0.659 → 0.577 (−12 %);
  - ценность слоёв почти та же. Без In1 / In2 / In4: C +6 / +45 / +3 %, B +28 / +29 / +4 %, A +23 / +23 / +5 %;
  - VDC и GND: виа там редкие, расхождение с cflow 2–10 %.
    - VDC C / B / A: 0.384 → 0.344, 0.365 → 0.324, 0.575 → 0.482 мОм (−10 / −11 / −16 %).
    - GND: C 0.291 → 0.282, B и A +0.5…1 %.
- Прочие допущения и их вес:
  - ρ взято при 20 °C. При 80 °C медь хуже на 23 %;
  - металлизация 25 мкм. При 18 мкм (типично для недорогих фабрик) узел A +3 %;
  - 35 мкм на внутренних слоях надо заказать явно: у многих фабрик внутри по умолчанию 0.5 oz;
  - VDC и GND считаются постоянным током со стоком в банки. Пульсации на 20 кГц и гармониках распределяются по индуктивности, модель даёт нижнюю границу их потерь;
  - пик |J| в углу пэда — особая точка, он растёт при мельчении сетки. Сравнивать варианты по нему нельзя.

**Последствие.**
- Решения по меди (фаза A, E6, сшивка VDC, «шунт B не трогать») остаются верными.
- Абсолютные числа в CHANGELOG и тепловой бюджет — нет.
  - Медь узла при 85–106 А RMS (120–150 А амплитуды): 4.3–7.3 Вт на фазу при 20 °C, до ~9 Вт горячая.
  - Шунт WSLF2512 300 мкОм добавляет 2.2–3.4 Вт.
  - По числам cflow выходило 2.8–4.4 Вт на медь.
- Фаза B не «лучшая» (0.24 мОм): она как C.
- Следующие решения нельзя принимать по нынешней модели: «сверхпроводящие» поля виа завышают пользу виа. Это In1 узлом в проходе C и виа в пэде шунта.

**Что сделать.**
1. `cflow.py`:
   - читать `size` виа из платы;
   - связывать стакан с медью слоя по кругу r = d/2 + металлизация, или вырезать отверстие и связывать кольцо у стенки;
   - проверять сходимость h 0.1 / 0.05.
2. Пик |J| заменить потерями в окрестности пэда или перцентилем |J| в кольце.
3. Пересчитать таблицы CHANGELOG. Тепловой бюджет прохода и шунта считать по исправленным числам.

### P16 — средняя для 48 В, высокая для 72–84 В. Датчики тока: у INA240 мал запас по синфазному с обеих сторон; у INA241A2 вывод 4 надо заземлить
**Где.** U4 / U9 / U12 на B.Cu, y 107.25.
- IN− (выв. 1) — Phase_IN, IN+ (выв. 8) — Phase_OUT. Подключены прямо к пэдам шунта, без R.
- Выв. 4 — `unconnected-(U12-NC-Pad4)`, у U4 и U9 так же.

**Факты.**
- Распиновка INA240 (SOIC-8, SBOS662C) и INA241 (D, SBOSA30D) совпадает с AD8418: 1 IN−, 2 GND, 3 REF2, 4 NC, 5 OUT, 6 VS, 7 REF1, 8 IN+. Полярность выхода прежняя.

| | INA240 | INA241A2 |
|---|---|---|
| Синфазное, рабочее | −4…80 В | −5…110 В |
| Синфазное, предел | −6…90 В | −20…120 В |
| Дифференциальное, предел | ±80 В | ±30 В |
| Вывод 4 (NC) | «connect to ground or leave floating» | «Reserved. Connect to ground» |

- **48 В, верх.** Стенд, 120 А: на выключении LS узел 83–87 В. Это выше рабочего диапазона INA240 и в 3–7 В от предела.
- **48 В, низ.** Не мерили.
  - После Кельвина HS выброс HS ожидается 20–27 В (05 P3).
  - На диод LS и его часть петли (корпус LS + путь исток → In3, ≈ 0.35–0.45 из 1.25 нГн) приходится узел ниже GND усилителя на ≈ −5…−10 В, на единицы наносекунд. Это оценка.
  - Предел INA240 — −6 В.
- **72 В:** шина + выброс = 100–110 В на выводах. INA240 за пределом, INA241 — в рабочем диапазоне.
- **84 В:** при R_on 0.82 Ом на кристалле 104–114 В (07 P13), на выводах на 8–11 В меньше, ≈ 95–105 В. INA241 — в рабочем диапазоне, до предела 15–25 В.

**Последствие.**
- 48 В без снабберов: INA240 на каждом выключении LS выходит за рабочий диапазон, а на выключении HS, вероятно, уходит ниже −6 В. Риск — ошибки после фронта и деградация входов.
- Замена на INA241A2 «пин в пин» неполная: вывод 4 по даташиту заземляется, а на плате он свободен.

**Что сделать (решает владелец).**
1. Вывод 4 U4 / U9 / U12 соединить с GND. Выв. 3 (GND) — рядом, 1.27 мм, на B.Cu. Для INA240 это допустимо, для INA241 обязательно.
2. Ставить INA241A2 и на 48 В — он перекрывает оба выброса.
   - Цена: предел дифференциального ±30 В (важен только при обрыве шунта).
   - Полоса 1.1 МГц вместо 400 кГц; фильтр OCP ≈100 кГц (S3) остаётся.
3. Если на 48 В остаётся INA240 — ставить LS-снабберы и снять U.8 и U.1 относительно U.2 на обоих фронтах (см. стенд).

### P19 — низкая. R снаббера 2 × 0805 на пэдах 0612: мощность подтверждаю; нужны класс резисторов и свой трафарет
**Где.** R100–R105 (футпринт 0612, пэды 1.18 × 3.40 мм, зазор 0.5 мм).

**Факты.**
- Модель: фронт узла линейный, ветвь L 1.1 нГн – R 0.5 Ом – C 4.7 нФ. Энергия в R за один фронт, мкДж:

| Шина | 6 нс | 10 нс | 20 нс | 30 нс | ½CV² |
|---|---|---|---|---|---|
| 48 В | 3.8 | 2.5 | 1.3 | 0.8 | 5.4 |
| 72 В | 8.5 | 5.7 | 2.8 | 1.9 | 12.2 |
| 84 В | 11.5 | 7.8 | 3.9 | 2.6 | 16.6 |

- Два фронта за период 20 кГц плюс звон (≤ 0.05 Вт). При 72 В на снаббер: 0.39 / 0.28 / 0.16 / 0.13 Вт для фронта 6 / 10 / 20 / 30 нс.
  - Числа CHANGELOG (0.28–0.39 Вт) — фронты 6–10 нс, верхняя граница.
  - При фронте напряжения ~29 нс (05 P6) — 0.13–0.16 Вт.
- Пиковый ток цепочки 40–62 А при фронте 6–10 нс, по 20–31 А на каждый 0805; импульс 3–4 мкДж.
- Индуктивность: 2 × 0805 ≈ 0.35–0.45 нГн против 0.25–0.3 нГн у 0612. Это +0.1 нГн ветви, ≈ +0.3 В на кристалле, не важно.
- Снижение мощности с нагревом (у обеих серий — до 0 при 155 °C):
  - ERJ-P06, 0.5 Вт при 70 °C: 0.38 Вт при 90 °C, 0.32 Вт при 100 °C;
  - ESR10, 0.4 Вт при 70 °C: 0.31 / 0.26 Вт.
  - На каждый 0805 при 84 В — 0.18–0.26 Вт (верхняя граница).
- Паста: футпринт 0612 даёт пасту на весь пэд 1.18 × 3.40 мм. Под 0805 пэд заходит под корпус на ~0.35 мм дальше обычного (зазор 0.5 мм против ~0.9). Лишняя паста под корпусом даёт шарики припоя.

**Что сделать.**
1. ERJ-P06 или равный антиимпульсный 0805 ≥ 0.5 Вт, 2 × 1 Ом (номинал 1 Ом в серии сверить). ESR10 для 84 В — без запаса.
2. Окна трафарета — только под выводы 0805, или отдельный футпринт «2 × 0805» с той же медью.
3. Нагрев — тепловизором (уже в списке стенда).

### P20 — низкая. VDC на J6: падение и зазоры в норме, но предохранителя нет — плавкой вставкой станет дорожка 0.4 мм внутри платы
**Где.** VDC: In2 (121.0, 73.4) → (121.0, 91.3) → виа (120.0, 92.3) → In1 через проход C → J6.1. J6.1–4 — VDC.

**Факты.**
- Длина 35.1 мм (In2 19.3 + In1 15.8 мм), ширина 0.4 мм: ≈ 43 мОм плюс виа. Цифру CHANGELOG подтверждаю. Ток соединительной платы — десятки мА, падение — милливольты.
- Зазоры на внутренних слоях:
  - до виа узла на In1 — 0.29–0.30 мм (до стенки отверстия 0.39 мм);
  - до отверстий стока Q4 / Q8 на In2 — 0.25 мм;
  - до GND — 0.25 мм.
  - IPC-2221B B1: 0.1 мм до 100 В, 0.2 мм до 300 В. Проходит и при выбросах.
- Связь с узлом:
  - ≈ 9 мм под медью узла F.Cu (0.1 мм) и над In2 узла — ≈ 2–2.5 пФ, при 10 В/нс это импульс ≈ 25 мА в J6;

  - начало теперь у банок, а не в петле коммутации. Это лучше, чем было.

**Последствие.** КЗ на соединительной плате выжигает внутренний слой силовой платы в проходе C, с риском дуги при 84 В. Так было и до F15: тогда та же дорожка шла по In2.
