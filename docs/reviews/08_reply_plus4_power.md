# Ответ на ревью 07 (силовая часть), ветка `rev0.1-plus4`

**Где правки.**
- Скрипт: `tools/rev01_layout/lay_P4b.py`, он же последний шаг `plus4.sh`. Коммит — этот, вместе с ответами.
- Запись: `CHANGELOG_rev0.1.md`, раздел «Ревью ветки `rev0.1-plus4`, раунд 2».
- DRC после правок: 0 ошибок, 0 неразведённых, 0 расхождений. ERC — 9 (база).

**Перепроверка утверждений ревью.**
- **P9.**
  - `hv.py`, где средняя точка X отнесена к своей цепи: на `ea2d599` — 41 место < 0.5 мм, на `515455d` — 24. Подтверждаю.
  - Своим замером (по прямоугольникам пэдов): R100.1 ↔ виа GND (119.75, 74.85) — 0.358 мм, R102.1 ↔ Q11.D — 0.347 мм. В ревью
    по DRC — 0.416 и 0.457; порядок тот же.
  - Причина подтверждается: у LS-цепочек сдвиг R относительно своего ключа −3.15 / −2.85 / −2.45 мм, у HS — −4.1 / −3.6 /
    −3.8 мм.
- **P12.** У ключа 28 отверстий Ø0.3 со слоями `*.Cu *.Mask`, на плате их 336. В настройках платы plugging, filling и
  capping выключены (tenting только сверху). Окно B.Mask доходит до кромки паза: моим растром 0.00 мм. Подтверждаю.
- **P14.** На B.Cu над колонками узла в полосе меди нет (картинка слоя). Подтверждаю.
- **P10, P11, P13** — модель ревьюера не пересчитывал. Входные данные сходятся с моими:
  - пэд C до D-пэда — 0.39 мм;
  - вывод R LS — 1.14 мм, вывод R HS — 1.46 / 1.21 / 1.29 мм;
  - C93 (141.4, 71.1), C94 (121.6, 69.7);
  - LTR18 — 1.5 Вт по даташиту.

**P9 — сделано (F12).**
- Средним точкам C112–C117.2 и R100–R105.1 — местный зазор 0.5 мм.
- Две оставшиеся близости убраны иначе, чем предлагалось, но без пересчёта места:
  - **Цепочка A** не сдвигается по x: −0.4 мм упирается в корпус C129 (фаза B), а уже при −0.2 R102.1 остаётся у Q11.D.
    Подняли цепочку на 0.06 мм по y — зазор до D-пэда Q11 стал больше 0.5 мм.
  - **Виа GND** (119.75, 74.85) перенесена в (119.35, 75.05). До R100.1 — 0.69 мм, до центра вывода S Q8 — 0.74 мм; число виа
    у выводов S (метрика §1.2) не меняется.
- В `hv.py` средняя точка LS теперь считается как GND, HS — как узел своей фазы. Результат: 24 места, как до удлинения.
- Проверено: DRC 0 / 0 / 0; перекрытий корпусов у деталей полосы нет (`crt_overlap.py`).

**P10 — согласен, записано в CHANGELOG.**
- L ветви ≈1.1 / 1.4 нГн.
- Выброс: на верхнем ряду −24…−28 %, на нижнем LS −23 %, на нижнем HS −12…−17 %. Ожидание −35 % снято.
- Мощность R: реально 0.1–0.2 Вт, верхняя граница 0.49 / 0.66 Вт.
- На стенде сначала C 6.8–10 нФ. Геометрию не менял.

**P11 — согласен.**
- Место HS-снаббера оставлено, вторая 1206 не ставится.
- «По две 0603 на фазу» — только по обозначениям. Это записано в CHANGELOG вместе с тем, какие стоят у стока: C92 / C90 / C95, C96.
- C93 и C94 ближе к стокам не встают: перебор `strip_plan.py` отдаёт место у стока снабберам и 1206.
- **Замена корпусов на тех же местах:**
  - 0612 обратной геометрии 1 мкФ 100 В не нашёл — поиск дал только LLL31 на 100 нФ при 50 и 16 В;
  - 2 × 0603 1 мкФ 100 В — правка схемы и BOM с учётом DC-bias при 72 В. Выношу владельцу.

**P12 — маска сделана (F14), остальное решает владелец.**
- Окна B.Mask узлов C и A отодвинуты от пазов на 1.5 мм (вырезан круг r 4.25). Открытой меди узла в 1.5 мм от кромки было
  9.2 / 12.6 мм², стало 0 / 0.1 мм². Медь и виа (Р8) не тронуты.
- Втулки с буртиком, отверстие в прокладке, заполнение и закрытие отверстий D-пэдов (IPC-4761 VII) в примечаниях к
  изготовлению, тип прокладки — в списке решений владельца.
- Испытание изоляции мегаомметром — в списке стенда.

**P13 — согласен.** R_on для 72/84 В — по Р5 (выброс против E_sw). Записано в решения владельца.

**P14 — сделано (F13).**
- Три зоны VDC только на B.Cu над колонками узла, y 71.0–73.65. VDC на B.Cu в полосе: 242 → 290 мм².
- Сечение VDC на y 74.1–74.2 не вернулось и вернуть его нельзя:
  - зона узла на B.Cu начинается с y 74.25, поэтому VDC держится в 0.6 мм от неё;
  - в `515455d` медь на этой линии над узлом B была за счёт того, что зона узла B (приоритет 4) уступала VDC — заливка узла B
    начиналась с 74.85;
  - над узлом медь VDC — тупик: ток VDC идёт в колонки стоков.
